# クイズ形式の設計メモ

クイズ全体を一つの形式に固定せず、5問それぞれに出題形式を割り振る。

形式の候補は、日本語の質問と日本語の選択肢、英語の質問と英語の選択肢、推論や要約を問う形式とする。

割り振りは完全な `Math.random()` ではなく、cycle ID などを seed にした再現可能なランダムにする。

同じ形式が5問すべて続かないようにし、5問中最低2種類の形式を含める。

初期の比率は、日本語の質問と日本語の選択肢を40%、英語の質問と英語の選択肢を40%、推論や要約寄りの形式を20%とする。

`relatedWords` は一つの問題に複数保持できるようにする。

`relatedWords` は問題と target word の関連、quiz feedback、後の分析に使う内部 metadata とする。

`relatedWords[0]` のように一つだけを学習者へ表示しない。

クイズの UI には、関連語ではなく質問文と選択肢だけを表示する。
